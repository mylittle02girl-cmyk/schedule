# スケジュール（iPhone用オフラインアプリ）

GitHub Pages で公開し、iPhone の「ホーム画面に追加」で使うオフライン対応のスケジュール管理アプリです。
データは iPhone 内（ブラウザの保存領域）にだけ保存され、外部には送信されません。

## 機能
- 月間カレンダー（月曜始まり・日本の祝日表示・左右スワイプで月移動）
- 日付をタップして選び、右下の＋で予定を追加（誤操作防止のため＋ボタンからのみ）
- 開始日〜終了日を指定して、複数日にまたがる予定を入力（カレンダー上は帯で表示）
- 予定ごとに「場所」「メモ」を入力
- 「終日」スイッチがオンの間は時間を入力できません
- 時間はテンキーで入力（開始・終了はそれぞれ独立して入力。例：`930` → 09:30、`1800` → 18:00、`9` + `:30` → 09:30、`+1時間` ボタン）
- テンプレート（固定の予定）を登録し、ワンタップで呼び出し
- 「複数日」モードで複数の日付を選び、同じ時間・内容の予定を一括登録
  - 曜日の見出し（月・火…）をタップすると、その月の同じ曜日をまとめて選択
- まとめて登録した予定は、削除時に「まとめて削除／この日だけ削除」を選べます
- バックアップ（JSON）の書き出し・復元
- 他のカレンダーアプリの .ics ファイルを取り込み（設定タブ。複数ファイル可・重複なし）

## GitHub への公開手順
1. GitHub で新しいリポジトリを作成（例：`schedule`、Public）
2. 「Add file」→「Upload files」で、このフォルダのファイルをすべてアップロード
   - `index.html` / `manifest.json` / `sw.js` / `icon-180.png` / `icon-192.png` / `icon-512.png`
3. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 1〜2分後に表示される URL（`https://ユーザー名.github.io/schedule/`）を iPhone の Safari で開く
5. 共有ボタン →「ホーム画面に追加」

一度開けば、以降は機内モードでも起動・入力できます。

## 更新するとき
`index.html` などを修正したら、`sw.js` の `VERSION`（例：`'v1'` → `'v2'`）も上げてアップロードしてください。
iPhone でアプリを2回ほど開き直すと新しい版に切り替わります。

## 注意
- ホーム画面に追加したアプリと Safari で開いたページは、データの保存場所が別です。普段はホーム画面のアプリから使ってください。
- 機種変更やアプリ削除に備えて、ときどき「設定」→「バックアップを書き出す」でファイルに保存してください。
